This plan is SENT: its header lists no packages yet. It may be free text or already formatted (headings, tables, numbered lists); cut it either way. Cut it first, before any Agent starts. Read the whole plan and the configured Agent providers above.
Step 1, requirements. Write every requirement of the plan text, none left out, into the state file beside the plan (<name>-STATE.md, a trailing -PLAN of the name dropped; create it if missing) under a heading "## Requirements", one line each in exactly this form: "- <id>: <requirement text>". Use the ids the plan author already gave (R1, 3.2, A-4 and so on) when the plan has them; otherwise number them R1, R2, R3 in plan order. Never change the plan text for this, only the state file.
Step 2, packages. Cut the plan into packages that are as small and sensible as possible, each doable by one agent alone. Write the TOML header (status, then one [[packages]] entry per package with id, title, class, depends_on, verify and requirements) above the unchanged Markdown text. requirements = ["R1", "R3"] lists the ids from the state file that the package covers; every requirement must be listed in at least one package.
Capability: work that only some providers can do (a capability that not every provider offers, for example image generation, 3D modelling or a full build, whenever a provider above lists it) becomes its own package with capability = "<name>" and contains no other work.
Parallel work: packages run in parallel. When a package needs the result of another one first, write that in depends_on; that package then waits and does not run in parallel. Packages that do not need each other have no depends_on between them, and no package depends on a capability package unless it needs its result.
Step 3: run bzz plan check --project {{project}} --plan {{plan}} until it reports ok; it sets the plan to QUEUED. It refuses the cut while a requirement in the state file belongs to no package (or a package names an unknown requirement); then cut again and add the requirement to a package. If the plan is unclear on a point only the owner can decide, ask with bzz ask. bzz agent start is refused until the check passed.
